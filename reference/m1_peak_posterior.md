# Compute the M1 peak-time posterior

Compute the M1 peak-time posterior

## Usage

``` r
m1_peak_posterior(...)
```

## Arguments

- ...:

  Arguments passed to
  [`m1_v2_peak_posterior()`](https://lennon-li.github.io/PAGe/reference/m1_v2_peak_posterior.md).

## Value

A peak-time posterior result.
