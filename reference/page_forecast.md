# Forecast with the current PAGe production release

Runs the current governed production forecast for a canonical
surveillance panel, OLIS snapshot, or supported ORVT input.

## Usage

``` r
page_forecast(...)
```

## Arguments

- ...:

  Arguments passed to
  [`page_v3_forecast()`](https://lennon-li.github.io/PAGe/reference/page_v3_forecast.md).

## Value

The current PAGe forecast result.
