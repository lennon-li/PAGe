# Single-season fractional M0 detector helper

Single-season fractional M0 detector helper

## Usage

``` r
detectIgnition_oneSeason_timing_v2(d_now, params)
```

## Arguments

- d_now:

  One-season detector data containing the standard M0 columns.

- params:

  M0 detector parameters.

## Value

A list with current detector signals and integer/fractional timing.
