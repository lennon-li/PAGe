# Aggregate joint forecast draws across strata

Preferred aggregation path when posterior or simulation draws are
available.

## Usage

``` r
aggregate_strata_draws(...)
```

## Arguments

- ...:

  Arguments passed to
  [`page_aggregate_strata_draws()`](https://lennon-li.github.io/PAGe/reference/page_aggregate_strata_draws.md).

## Value

A \`page_strata_aggregate_draws\` object.
