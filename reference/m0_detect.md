# Detect epidemic ignition with M0

Advanced model-level runtime interface for the ignition component.

## Usage

``` r
m0_detect(...)
```

## Arguments

- ...:

  Arguments passed to
  [`run_m0()`](https://lennon-li.github.io/PAGe/reference/run_m0_detection.md).

## Value

The current M0 ignition state.
