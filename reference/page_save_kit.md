# Save a validated frozen PAGe deployment kit

Save a validated frozen PAGe deployment kit

## Usage

``` r
page_save_kit(x, path, overwrite = FALSE)
```

## Arguments

- x:

  A \`page_training_workflow\`, \`page_training_result\`, or PAGe kit.

- path:

  Destination \`.rds\` path.

- overwrite:

  Allow replacing an existing file.

## Value

Normalized saved path, invisibly.
