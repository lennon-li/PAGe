# Validate a governed M2-v2 C2 artifact

Validate a governed M2-v2 C2 artifact

## Usage

``` r
validate_m2_v2_c2_governed_artifact(x)
```

## Arguments

- x:

  Object produced by the governed M2-v2 C2 artifact builder.

## Value

\`x\` invisibly when contract and deterministic identity checks pass.
