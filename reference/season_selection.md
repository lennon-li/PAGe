# Extract the season selection from a stage artifact

Generic accessor for the normalized `page_season_selection` recorded in
a stage result, kit, or replay result.

## Usage

``` r
season_selection(x, ...)
```

## Arguments

- x:

  A stage artifact (fit, tuning result, or kit).

- ...:

  Reserved for method extensions.

## Value

A `page_season_selection` object.
