# Run the governed M2-v2 C2 forecast path

A timing failure abstains to the fitted type baseline. B +1 is always
B1. B +2 remains B1 until a review object explicitly opens the
artifact's exact causal gate version. This function does not alter
run_prospective_pipeline().

## Usage

``` r
run_m2_v2_c2_governed_runtime(
  artifact,
  weekly_data,
  origin_week,
  a_handoff = NULL,
  b_handoff = NULL,
  b_gate_review = NULL
)
```

## Arguments

- artifact:

  Validated governed M2-v2 C2 artifact.

- weekly_data:

  Three or more typed weekly rows used by the research runtime adapter.

- origin_week:

  Current week in season-relative coordinates.

- a_handoff:

  Optional governed A M1 timing handoff.

- b_handoff:

  Optional type-B soft-timing handoff.

- b_gate_review:

  Optional reviewed gate opening from new_m2_v2_b_gate_review().

## Value

Governed output contract with prediction rows and provenance.
