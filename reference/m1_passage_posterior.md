# Compute the M1 peak-passage posterior

Compute the M1 peak-passage posterior

## Usage

``` r
m1_passage_posterior(...)
```

## Arguments

- ...:

  Arguments passed to
  [`m1_v2_passage_posterior()`](https://lennon-li.github.io/PAGe/reference/m1_v2_passage_posterior.md).

## Value

A peak-passage posterior result.
