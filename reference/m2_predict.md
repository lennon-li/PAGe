# Predict with M2

Advanced model-level runtime interface for the short-horizon component.

## Usage

``` r
m2_predict(...)
```

## Arguments

- ...:

  Arguments passed to
  [`run_m2()`](https://lennon-li.github.io/PAGe/reference/run_m2_forecast.md).

## Value

One- and two-week-ahead M2 forecast output.
