# Aggregate stratified forecasts

Stable public wrapper for analytic aggregation across arbitrary strata.

## Usage

``` r
aggregate_strata(...)
```

## Arguments

- ...:

  Arguments passed to
  [`page_aggregate_strata()`](https://lennon-li.github.io/PAGe/reference/page_aggregate_strata.md).

## Value

A \`page_strata_aggregate\` object.
